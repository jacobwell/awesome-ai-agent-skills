# Changelog

All notable versioned releases of Awesome AI Agent Skills are documented here.

## [1.0.0] - 2026-08-09

### Added

- A reproducible Production Agent Stack demo combining agent evaluation, observability, bounded tool schemas, simulated approval records, prompt-injection boundaries, and a synthetically authorized offline red-team replay.
- Paired fragile and controlled fixtures for a poisoned-issue deployment scenario.
- Runtime-generated evaluation, trace, approval, trust-boundary, red-team, release-decision, and checksum evidence.
- CI execution of the complete offline demo on pushes, pull requests, and version tags.
- Twelve advanced skills for agent engineering, agent security, document workflows, and AI governance.

### Included

- 103 self-contained Agent Skills across 21 categories.
- One-command installation through the Skills CLI.
- Compatibility with Claude Code, OpenAI Codex, Gemini CLI, Cursor, GitHub Copilot, Windsurf, and other Agent Skills-compatible tools.
- Catalog validation for structure, metadata, local links, duplicates, skill count, and bundled Python syntax.

### Safety note

The demo validates committed synthetic fixtures and structural evidence contracts. It does not certify any model, deployed agent, implementation, or organization as secure, compliant, or production-ready.
